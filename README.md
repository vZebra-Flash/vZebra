TECHNICAL DETAILS
─────────────────

• Video codec: FFV1 (mathematically lossless, royalty-free)
• Audio codec: FLAC (mathematically lossless, royalty-free)
• Container: MKV (Matroska, open standard)
• Bit depth: 16-bit (always — regardless of source)
• Chroma: 4:4:4 (full chroma, no subsampling)
• Color gamut: preserved from source (BT.709 or BT.2020 SDR)
• Color range: preserved from source (limited or full)
• Color pipeline: ACES-based Narkowicz tone mapping
• Encoding: CPU-based, no GPU required
• Fully royalty-free codec stack — no HEVC, no H.264,
  no AAC, no MP3
• FFmpeg engine bundled — no external installation required


OUTPUT FILE SIZE
────────────────

vZebra delivers a mathematically lossless 16-bit master.
This means the output will be significantly larger than
your source file.

This is by design. Every bit of detail from your original
film is preserved.

Compress the master yourself using HandBrake, CapCut, or
DaVinci Resolve for smaller delivery files.
